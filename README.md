# aislop-projects

### Bienvenue sur aislop-projects, un regroupement de projets issus du vibe coding !

Chaque projet dispose de son propre dossier contenant le ou les fichiers générés par vibe coding, ainsi que les messages envoyés à l'IA et les fichiers de contexte ou les discussions associés au projet.

Tous les projets proviennent des serveurs Discord Makers Hub by Aywen et Baudo BOYZ.

Je les ai regroupés ici afin qu'ils soient facilement accessibles et consultables, sans avoir à remonter toute une conversation pour les retrouver.

Pour le moment, je suis le seul contributeur. Cependant, si le raz-de-marée des vibecoders continue, je serai dans l'obligation d'accueillir de nouveaux contributeurs !

- Quelques règles :

Les règles des deux serveurs Discord s'appliquent également ici.

Tous les codes des projets présentés ici ont été publiés avec l'accord de leurs auteurs respectifs, c'est-à-dire des personnes ayant rédigé les prompts.
